# Выпуск Bridge 0.18.2

Готовая сборка: [bridge-0.18.2-lite.zip](../../dist/bridge-0.18.2-lite.zip).
Полный комплект: [bridge-chrome-web-store-0.18.2.zip](../../dist/bridge-chrome-web-store-0.18.2.zip).
Распакуйте комплект и откройте `START_HERE.html`: поля с копированием,
два набора текстов EN/RU, пять скриншотов 1280×800, иконка, два баннера, политика и инструкция проверяющему.
Публикация в Chrome Web Store ещё не выполнена.

Основной пакет содержит общий локальный движок, интерфейс и каталог 53 голосов
для 49 языков. Акустические модели скачиваются только после выбора отдельного
голоса; остальные языки не устанавливаются. Установленный голос хранится
в IndexedDB и работает без сети. Голос можно удалить в настройках Bridge.

На YouTube перевод предоставляет сайт. На других поддерживаемых площадках
используются готовые субтитры или локальный Translator Chrome 138+.
Голос и перевод имеют отдельные статусы доступности. Не все языки и пары
поддерживаются; приложение не подменяет отсутствующий перевод исходным текстом.

Издателю остаётся загрузить внутренний ZIP из `01-upload` в кабинет,
перенести подготовленные поля и изображения, заполнить свой профиль/контакты
и опубликовать политику по общедоступной HTTPS-ссылке. В `START_HERE.html`
есть форма, которая добавляет имя/email в скачиваемую HTML-политику локально.
После проверки и публикации пользователи смогут устанавливать расширение
кнопкой магазина. До публикации установка этой сборки — из распакованной папки.

Названия: «Bridge — Subtitle Voice & Translation» (English) и
«Bridge — озвучка и перевод субтитров» (Русский). Основной язык — en,
дополнительный — ru, категория Accessibility, видимость Public.
[English description](listing-en.txt) · [Русское описание](listing-ru.txt).
В `START_HERE.html` есть отдельные поля копирования для каждого языка;
в кабинете переключайте язык карточки, а не объединяйте тексты в одно поле.
Полный список площадок вынесен на скриншот. [Инструкция по загрузке](publishing-guide-ru.md).

Повторная сборка комплекта: `npm run store:kit`. Обновление изображений:
`npm run store:assets` (Playwright, Chromium, sharp и сохранённая локальная
модель из archive нужны только для подготовки снимков). Самим пользователям
Node.js и эти инструменты не нужны. Иллюстрация деморолика и баннеры
созданы кодом; снимки показывают настоящий интерфейс и локальный синтез.

Условия отдельных голосов указаны до установки в карточке «Источник и условия»;
не следует объявлять все модели MIT или обещать оба типа голоса для каждого языка.
eSpeak NG в общем модуле произношения имеет GPL-3.0-or-later. В ZIP сохранены
лицензии и соответствующие исходники; все исполняемые JS/WASM локальны.

Инструкции Google: [публикация](https://developer.chrome.com/docs/webstore/publish),
[карточка](https://developer.chrome.com/docs/webstore/cws-dashboard-listing).
