# Загрузка Bridge в Chrome Web Store

Распакуйте общий комплект и откройте START_HERE.html. Он содержит кнопки
копирования для каждого поля и предпросмотр всех изображений.

1. Зарегистрируйте/откройте [кабинет разработчика](https://chrome.google.com/webstore/devconsole).
   Регистрация нового аккаунта платная; актуальная сумма и требования указаны Google.
2. Добавьте новый элемент и загрузите ZIP из папки `01-upload`.
   Не загружайте общий архив комплекта. Внутренний ZIP уже имеет manifest в корне.
3. Основной язык — English, дополнительный — Russian; категория — Accessibility,
   распространение — Free / Public. В пакете есть `_locales/en` и `_locales/ru`:
   магазин берёт названия и короткие описания из соответствующих messages.json.
   В Store listing выберите English и вставьте `02-listing/description-en.txt`,
   затем Russian и вставьте `02-listing/description-ru.txt`. Не объединяйте оба
   текста в одном языковом поле. Для сверки рядом есть `title-en.txt`, `title-ru.txt`
   и `short-description-en.txt`, `short-description-ru.txt`. Поисковые фразы уже
   включены в описания; отдельный список тегов добавлять не нужно.
4. Добавьте пять PNG из `03-images/screenshots` по номеру. Иконка 128×128 уже
   включена в пакет. В дополнительные поля добавьте баннеры 440×280 и 1400×560.
   Видеообзор и адрес сайта продукта можно оставить пустыми, если их нет.
5. Заполните Privacy по `04-review/privacy-practices.txt`. Обработка текста,
   URL текущего видео и состояния плеера раскрыта, хотя она локальная. Remote
   code — No: исполняемые JS/WASM внутри ZIP, модели — проверенные данные.
6. В START_HERE можно вписать имя издателя/email и скачать политику с контактами.
   Разместите `05-privacy/privacy-policy.html` по публичному HTTPS-адресу и
   вставьте ссылку в Privacy policy URL. Файл на диске эту ссылку не заменяет.
7. Добавьте `04-review/reviewer-instructions-en.txt` в Test instructions.
   Учётные данные и API-ключи Bridge не нужны.
8. В профиле издателя укажите свои контакты и выполните требования кабинета.
   Выберите нужные регионы и отправьте на проверку. Можно разрешить
   автоматическую публикацию после одобрения.

После публикации пользователи устанавливают расширение обычной кнопкой
магазина с подтверждением Chrome. Голос выбирается при первоначальной
настройке. Сам ZIP не создаёт публичную карточку и не выполняет отправку.
Поиск и одобрение не гарантируются; карточка подготовлена без вымышленных
отзывов, рейтингов и обещаний перевода любого видео.

## Что в комплекте

- `01-upload` — только архив расширения и SHA-256.
- `02-listing` — названия и короткие/полные описания EN/RU, метаданные и заметки о поиске.
- `03-images` — иконка, пять скриншотов, промоизображения, исходные SVG/снимки.
- `04-review` — ответы по разрешениям/данным и сценарий проверки.
- `05-privacy` — политика в HTML/Markdown и инструкция размещения.

Снимки сделаны с настоящим интерфейсом и настоящей локальной моделью на
авторском демонстрационном ролике. Два снимка используют композицию с
увеличенным реальным фрагментом интерфейса. Демо не подменяет поддержку
субтитров на любом живом ролике. Модели не входят в основной ZIP.
