Общий архив комплекта сначала распакуйте. Внутренний ZIP уже содержит manifest.json в корне — его распаковывать перед загрузкой в магазин не нужно.

1. Загрузите расширение

  1. Войдите в аккаунт разработчика Chrome Web Store. Для нового аккаунта Google потребуется регистрация и её разовая оплата по тарифу в кабинете.
  2. Нажмите Add new item / «Добавить новый элемент» и выберите 01-upload/bridge-%%VERSION%%-lite.zip.
  3. Проверьте версию %%VERSION%%. Название и короткое описание магазин возьмёт из manifest.

Кабинет Google может менять названия пунктов. Актуальная инструкция: публикация расширения.

2. Заполните Store listing / «Карточка»

Язык: русский · Категория: Accessibility / «Специальные возможности» · Стоимость: Free

Поисковые фразы уже встроены в текст. Не добавляйте блок «тегов», повторы ключевых слов или названия конкурентов. Пояснение о поиске.

3. Загрузите изображения

Скриншоты 1280×800 загружайте в указанном порядке. На них настоящий интерфейс Bridge и авторский демонстрационный ролик; возможности не подменены нарисованным интерфейсом.

4. Privacy / «Конфиденциальность»

Обоснование разрешений

Раскройте раздел и скопируйте текст в соответствующее поле Google.

%%PERMISSIONS%%
Remote code / Удалённый код — No

Использование данных

Укажите Website content, Web history, User activity. Остальные типы из подготовленной таблицы не используются. Это локальная обработка текущих субтитров, URL видео и состояния воспроизведения, а не выгрузка истории просмотра разработчику.

Не выбирайте «данные вообще не обрабатываются»: расширение читает текст и состояние страницы. Google требует раскрывать и локальную обработку.
Пояснение по данным

Подтвердите три заявления об использовании данных, если публикуете именно эту сборку без изменения её поведения:

    %%CERTIFICATIONS%%

Все ответы одним файлом · Правила локальной обработки

5. Разместите политику по публичной ссылке

Это обязательный шаг с вашей стороны.
В Chrome Web Store нужна общедоступная HTTPS-ссылка. Локальный HTML или путь на компьютере не заменяют её. Политика уже написана; разместите её на своём сайте, статическом хостинге или публичной странице без входа.

Открыть готовую политику Скачать HTML

Добавить своё имя и email в политику перед размещением

Данные останутся в этом браузере и попадут только в скачанный вами HTML. Они не отправляются сервису.

После размещения откройте ссылку в режиме инкогнито. Страница должна читаться без авторизации. Вставьте этот URL в поле Privacy policy URL. Публичный email и профиль издателя заполните в кабинете Google своими данными.

6. Инструкция для проверяющего

В разделе Test instructions добавьте подготовленный текст. Тестовый логин Bridge не нужен.

7. Опубликуйте

В Distribution выберите Public, нужные регионы и бесплатное распространение. Затем отправьте расширение на проверку. При желании включите автоматическую публикацию после одобрения.

После одобрения появится обычная кнопка установки из магазина с подтверждением Chrome. Первую голосовую модель пользователь выбирает отдельно; подходящий голос ОС можно использовать без установки модели.

Рассмотрение, индексация и место в поиске зависят от Google. Публикация этим комплектом не выполняется.
