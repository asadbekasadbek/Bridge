Языки и звучание

Оба языка запоминаются автоматически.

«Автоматически» определяет язык по дорожке YouTube. Ручной выбор использует доступные исходные субтитры на выбранном языке.

Выбор сохраняется сразу. Ниже отдельно показаны доступность перевода и голоса. Установите только тот голос, который хотите слушать.

«Авто» приблизительно подбирает тембр по коротким фрагментам звука, без нейросети. В плеере можно в любой момент выбрать «Женский» или «Мужской» для текущей и следующих реплик. Для проверки ниже используется выбранный локальный голос.

Локальный голос

При установке скачиваются только файлы модели; текст не отправляется. Речь работает на компьютере. На YouTube перевод делает сайт, на остальных площадках доступен локальный перевод Chrome.

Лёгкий режим включён по умолчанию: один голос в памяти и выгрузка после минуты простоя. Установленные файлы сохраняются. Для быстрых переключений двух голосов можно отключить экономию памяти. Старые ноутбуки требуют отдельной проверки.
