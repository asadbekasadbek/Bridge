# Included third-party components

Bridge uses the following locally packaged components. All executable JS/WASM is packaged locally. Optional voice models/configurations are downloaded only on request from a pinned upstream repository and its CDN.

- **ONNX Runtime Web 1.30.0**, Microsoft Corporation, MIT. Unmodified `ort.wasm.min.mjs`, `ort-wasm-simd-threaded.mjs`, and `ort-wasm-simd-threaded.wasm` from the npm `onnxruntime-web` distribution. License: `onnxruntime-MIT.txt`. Source: https://github.com/microsoft/onnxruntime
- **Optional Piper voices**, from https://huggingface.co/rhasspy/piper-voices/tree/5041a7a49ae5b3a0f30e6837769eb03fdbb231bd . No acoustic weights are included in the base ZIP. Each requested ONNX model and JSON configuration is unmodified and checked against the sizes and SHA-256 values in `shared/voice-pack-catalogue.js`. Voice-specific model cards are included under `voices/catalogue/`; their license/data declarations differ, including noncommercial and unspecified terms. See `voice-packs.md`. The repository-level MIT declaration (`../voices/README.upstream.md`) does not replace those declarations. Piper's MIT notice is included as `piper-MIT.txt`.
- **Piper phonemize 1.2.0 / @diffusionstudio/piper-wasm 1.0.0**, Michael Hansen, Konstantin Paulus and contributors. Binary/data obtained from the versioned npm package, whose metadata declares MIT; phonemize source is MIT (`piper-phonemize-MIT.txt`). The WASM also links **eSpeak NG**, GPL-3.0-or-later (`espeak-ng-GPL-3.0.txt`), and must not be represented as wholly MIT. Sources: https://github.com/diffusionstudio/piper-wasm , https://github.com/wide-video/piper-phonemize/tree/cfff8e52ebaea37c7e953ae2d06b174acb827ac4 , https://github.com/rhasspy/espeak-ng/tree/0f65aa301e0d6bae5e172cc74197d32a6182200f . Corresponding source archives, upstream build instructions and the original JS loader are supplied in `sources/`. Nested source licenses (including uni-algo, nlohmann JSON and Unicode data) are retained in those archives. No eSpeak waveform is played: eSpeak supplies pronunciation IDs to Piper.

Bridge 0.18.1 distributes a shared speech runtime and metadata catalogue for 53 optional voices in 49 languages. Each voice is installed and removed separately. Compatible local OS voices are also supported. Bridge does not train voices or claim ownership of recordings. Runtime source revisions and SHA-256 checksums are recorded in `../voices/assets.lock.json`; voice download checksums are in the catalogue.

Bridge adapts the JS loader to ES modules and uses bounded reusable argument storage instead of leaking the WASM stack on every `callMain`. Its pronunciation adapter refreshes only native CLI state in bounded batches using cached local bytes and one compiled WebAssembly module; the ONNX session remains loaded. The loader also avoids copying the supplied WASM bytes at each reset. Modifications are dated 2026-10-26 and visible in the included JS sources. The project script `scripts/prepare-vendor.mjs` deterministically rebuilds this adaptation from the pinned original loader and validates its SHA-256 against `voices/assets.lock.json`; it runs on dependency installation. Build recipe: `sources/piper-wasm-build.md`; original loader: `sources/piper_phonemize.original.js`.

`speech/russian-text.js`, extension integration and UI are Bridge project code. `examples/bridge-denis.wav` is synthesized locally from “Привет! Как ваши дела?”. It is an example; arbitrary subtitles are synthesized at runtime.
