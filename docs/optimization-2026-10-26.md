# Bridge 0.17.1: оптимизация и исправления

Проверено 26 октября 2026 года. Исходное состояние проходило 106 тестов; после
добавления проверок найденных случаев проходят 121 из 121. Общий процент
ускорения и отсутствие любых возможных ошибок не заявляются.

## Изменения

| Участок | Что изменено и зачем |
| --- | --- |
| Установка голосов | Сетевые фрагменты сразу записываются в один буфер закреплённого размера. Убрано одновременное хранение всех фрагментов и второй полной копии модели. Для Дениса устраняется один дополнительный буфер примерно на 60 МиБ; это оценка буферов загрузчика, не замер полной памяти браузера. |
| Отмена установки | Отмена повторно проверяется после чтения потока и проверки SHA-256, до начала записи пакета. Отменённая на этом этапе установка больше не публикует голос. Уже завершённая запись сохраняется. |
| Ошибки загрузки | Незавершённый поток отменяется, reader освобождается перед повтором. Оборванный файл отклоняется по фактически прочитанной длине. |
| Piper | Скомпилированный `WebAssembly.Module` переиспользуется при сбросах native CLI. Исходный WASM-буфер больше не копируется на каждом сбросе. Ограничение в 8 CLI-вызовов на экземпляр и ограниченный argv сохранены. |
| ONNX | Используется готовый массив CPU-аудио без дополнительного `Float32Array.from`. Входные и выходные тензоры освобождаются при успехе и при ошибке. |
| Передача PCM | Если звук превышает лимит кэша, его полный буфер сразу передаётся в offscreen. Кэшируемое аудио и срезы продолжают копироваться, чтобы передача не отсоединяла сохранённый буфер. |
| Освобождение моделей | Ошибка native release не оставляет повреждённую запись в LRU и не останавливает очередь. Освобождение графа выполняется по возможности; при простое весь Worker по-прежнему завершается. |
| Отмена речи | Поздний результат чтения списка голосов и позднее открытие offscreen не запускают отменённый прогрев. Ошибка отменённой реплики не выключает следующую. Независимые запросы списка голосов ОС и установленных пакетов выполняются параллельно. |
| Перевод | Заранее отменённая подготовка не начинает загрузку. Ожидающая реплика не переходит на другую языковую пару. Выбор совпадающих языков освобождает предыдущий переводчик и кэш. |
| Длинные дорожки | Следующий субтитр ищется двоичным поиском. При определении исходного языка извлекаются только первые три cue, без копирования всей дорожки. |

Основание для использования CPU-массива после освобождения оболочки Tensor:
[контракт ONNX Runtime](https://github.com/microsoft/onnxruntime/blob/main/js/common/lib/tensor.ts).
Поведение дополнительно проверено настоящим WASM/ONNX-синтезом.

## Сохранение правок зависимости

`scripts/prepare-vendor.mjs` строит изменённый загрузчик из включённого оригинала
`extension/licenses/sources/piper_phonemize.original.js`. Скрипт проверяет SHA-256
исходника, однозначность мест изменения и SHA-256 результата в
`extension/voices/assets.lock.json`.

`postinstall` автоматически восстанавливает патч. Ручная команда:
`npm run vendor:prepare`. Повторный запуск не добавляет патч второй раз.
Восстанавливаются и удалённый файл, и файл, заменённый оригиналом. Неизвестная
версия исходника отклоняется. `check` и `package` проверяют подготовленный
загрузчик; сборка дополнительно проверяет все закреплённые runtime-ресурсы.

Установка с отключёнными lifecycle-скриптами требует отдельного запуска
`vendor:prepare`. Поведение `postinstall` проверено настоящим
`pnpm install --offline --lockfile=false` во временной копии проекта после
замены загрузчика исходной версией. Новых npm-зависимостей не добавлено.

## Выполненные проверки

- `node scripts/check.mjs`: manifest, согласованность версий, разрешения,
  локальные файлы, отсутствие inline JS и синтаксис JavaScript.
- `node --test tests/*.test.mjs`: 121 тест без ошибок.
- `browser-smoke.mjs`: настройки, сохранение и перезапуск, popup, узкий экран,
  ошибки, отсутствие голоса. Настоящий системный голос также завершил синтез
  при нулевой громкости.
- `youtube-browser.mjs`, `shorts-browser.mjs`, `platforms-browser.mjs`:
  управление, языки, очередь, пауза, SPA, iframe, Shadow DOM и смешивание.
  Источник субтитров тестовый, речь подменена.
- `translation-browser.mjs`: перевод, пауза, смена языка и ошибки, включая
  Shaka Udemy; API Translator и голос подменены.
- `voice-auto-browser.mjs`: настоящий captureStream/Web Audio на тестовых
  сигналах, выбор типа голоса и ручное переключение.
- `voice-compatibility-browser.mjs`: настоящий фонемизатор для всех 53 пакетов,
  ошибок нет. Акустическое качество всех голосов этой проверкой не оценивается.
- `optimization-browser.mjs`: настоящие Piper/WASM/ONNX, установка Дениса через
  загрузчик из сохранённых локальных файлов с проверкой размера/SHA-256,
  PCM-кэш, выгрузка графа, офлайн-речь после перезапуска и удаление пакета.
  Профиль временный; сетевых запросов и ошибок страницы нет.

В последней проверке Chromium 151.0.7922.34 фонемизатор обработал 80 фраз:
10 экземпляров CLI, одна компиляция WASM, два чтения файлов. Начальная подготовка
заняла около 29 мс, обработка фраз со сбросами — около 485 мс суммарно.
Синтез короткой фразы занял около 236 мс без учёта открытия модели;
повторная фраза использовала PCM-кэш без нового синтеза. Эти числа относятся
к текущему Mac и конкретному запуску, не к старым ноутбукам.

Машинный отчёт: `test-results/optimization-browser.json`.

## Границы проверки

Живые площадки, их переводческие серверы, все акустические модели и старые
версии Chrome повторно не проверялись. Настоящий Chrome Translator в этом
изменении повторно не тестировался; его адаптер покрыт модульными тестами
и браузерными fixtures. Качество голосов и исходные веса моделей не менялись.
Нельзя гарантировать отсутствие ошибок за пределами проверенных сценариев.

Готовый выпуск: `dist/bridge-0.17.1-lite.zip`. Для обновления замените файлы
в прежней папке расширения, нажмите обновление в `chrome://extensions` и
перезагрузите вкладки видео. Удалять расширение для обновления не требуется.
